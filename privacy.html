Политика конфиденциальности

Приложение Bunch

1. Общие положения

Приложение Bunch (далее — Приложение) разработано для развлечения: подбор смешных звуков и их воспроизведение по расписанию.

Разработчик: Панфилов Вячеслав Викторович. Контакт: takomak2012@yandex.ru

2. Какие данные собирает Приложение

Приложение не собирает и не передаёт персональные данные пользователя: в нём нет аккаунтов, собственной аналитики, идентификаторов пользователя и рекламных трекеров собственной разработки.

3. Данные, которые хранятся на устройстве

Настройки, избранное, счётчик серии дней, статистика проигрываний и записанные вами звуки хранятся только на вашем устройстве и удаляются при удалении Приложения.

4. Разрешения

  • Микрофон — запрашивается в момент записи своего звука и используется только для этой записи. Запись запускается исключительно по действию пользователя.
  • Точные будильники и отключение оптимизации батареи — открываются по выбору пользователя в настройках, чтобы звук срабатывал вовремя.
  • Уведомления — используются для уведомления о сработавшем будильнике и ежедневного напоминания, которое можно отключить.

Доступ к файлам пользователя Приложение не запрашивает: выбор своего аудиофайла выполняется через системный диалог выбора файлов.

5. Реклама

Приложение показывает рекламные блоки сети Яндекс (РСЯ) и рекламу с вознаграждением. Рекламные сети обрабатывают технические данные (в том числе идентификатор рекламного объявления и тип подключения) для подбора рекламы в соответствии со своими политиками конфиденциальности.

6. Дети

Приложение содержит юмористические звуки и подходит для любого возраста. Оно не совершает звонков, не отправляет сообщений и не собирает данные детей.

7. Изменения условий

Актуальная версия политики всегда доступна в Приложении: «Настройки» → «О приложении и политика».
