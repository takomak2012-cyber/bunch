# app-ads.txt

Файл нужен рекламным сетям (в первую очередь Яндексу / РСЯ), чтобы подтвердить,
что приложение принадлежит разработчику.

## Что уже сделано

Файл опубликован по адресу:
https://takomak2012-cyber.github.io/bunch/app-ads.txt

Это **общий файл разработчика** `takomak2012-cyber` — тот же самый, что используется
на сайтах остальных приложений (AlcoCalk, Parikmaher, ShahMatI, Tomagochi). Он содержит
строки для всех рекламных сетей, включая Яндекс:

```
yandex.com, 304816787, DIRECT
```

Для Bunch отдельная строка не нужна: `304816787` — это ID аккаунта РСЯ, а не ID
приложения. ID приложения `20249757` в app-ads.txt **не пишется**.

## Чего делать нельзя

- Нельзя заменять файл строкой `google.com, pub-20249757, ...` — это неверный формат
  для Яндекса, из-за него подтверждение домена не проходит.
- Нельзя сокращать общий файл до одной строки: остальные сети тоже должны видеть
  свои записи.

## Как Яндекс находит файл

1. В карточке приложения в RuStore в поле **«Веб-сайт»** указан адрес:
   `https://takomak2012-cyber.github.io/bunch/`
2. Яндекс запрашивает `https://takomak2012-cyber.github.io/bunch/app-ads.txt`
   и находит строку `yandex.com, 304816787, DIRECT`.
3. После этого приложение считается подтверждённым в РСЯ.

## Проверка

```powershell
(Invoke-WebRequest -UseBasicParsing "https://takomak2012-cyber.github.io/bunch/app-ads.txt").StatusCode
Select-String -Path site\app-ads.txt -Pattern "yandex.com"
```

Ожидается HTTP 200 и строка `yandex.com, 304816787, DIRECT`.
